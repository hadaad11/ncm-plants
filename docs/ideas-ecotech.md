# أفكار تطوير برنامج NCM Plants

**المصدر:** إعلان EcoTech (ecotech.mena) لبرنامج إدارة مصانع الخرسانة الجاهزة — اتراجع في 9 نوفمبر 2026.

## الخلاصة
البرنامج ده معمول لمصانع الخرسانة التجارية اللي بتبيع لعملاء كتير، فهنستفيد منه **كأفكار** مش كبرنامج نشتريه.
NCM شغالة لمشروع واحد (الضبعة)، فموديول عروض الأسعار والتعاقد **مش مطلوب**.

## الأفكار المقترحة

### 1. جدولة الصبّات حسب الطاقة
- تقويم للصبّات المطلوبة، وكل صبّة تتوزع على محطة (L1 / L2 / V3 / V4 / V5) حسب طاقتها وعدد الخلاطات المتاحة.
- لما صبّة تتأجل أو تتلغي، الجدول يتعدّل تلقائي.

### 2. متابعة الخلاطات (Truck Mixers)
- تسجيل زمن الخروج والوصول والتفريغ والرجوع لكل نقلة.
- حساب متوسط زمن الدورة، وعدد العربيات المطلوبة لكل صبّة.

### 3. المرتجع والهالك ⭐
- سجل للخرسانة المرتجعة أو المرفوضة: الكمية، السبب، المحطة، الخلطة.
- حساب تكلفة المواد الضايعة.

### 4. مكتبة الخلطات (Mix Design)
- الخلطات المعتمدة بالمقاومة والهبوط والإضافات، ومعاها رقم إصدار.
- مهم لأن الخلطات في المشروع النووي بتتعدّل بموافقات.

### 5. الاستهلاك الفعلي مقابل النظري ⭐
- مقارنة الاستهلاك الفعلي بالـ recipe لكل خلطة.
- عرض الانحراف لكل محطة.
- تطوير مباشر لتقرير استهلاك المواد الحالي.

## الأولوية
⭐ **البداية:** المرتجع والهالك + مقارنة الفعلي بالنظري، لأنهم الأسهل والأعلى قيمة، والبيانات موجودة أصلًا.

## مستبعد
- عروض الأسعار والتعاقد: مش مناسبة لطبيعة شغل NCM.
